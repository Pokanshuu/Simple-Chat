# v1.1.6 预发布验收

日期：2026-11-18。版本：1.1.6，构建号 28。发布渠道：GitHub Pre-release。
本页记录线上安装包的验收结果，不覆盖本地构建号 29 或之后的源码改动。

## 功能范围

- 独立搜索、网页读取与文件 API 配置，可使用独立密钥或复用聊天密钥。
- 大文件直接上传，长用户输入和文本附件按阈值转换为文件引用并复用上传结果。
- 分层压缩、请求超限自动缩批、中断恢复和压缩前附件正文完整性检查。
- DeepSeek v3 兼容备份，保留现有 JSON、ZIP 格式及其导入能力。
- Markdown 与 LaTeX 行内混排、连续引用竖线、公式段落完整布局。
- 双击 AI 回复进入原生选字，复用测量结果，保留分页、复制、拖选和退出行为。

## 备份兼容设计

“设置 > 数据管理 > 导出 DeepSeek 兼容备份”生成以下结构：

```text
manifest.json
user.json
chat_sessions/<session_id>.json
chat_session_index.json
chat_sessions/<session_id>_files/<file_id>_image
```

清单使用 `export_format_version: 3`。会话采用数值消息 ID、`parent_id`、`current_message_id` 和官方片段结构。
正文、思考、工具来源、链接阅读签名及图片映射到相应官方字段。
存在连续同角色或以助手开头的历史时，兼容视图插入空桥接节点以维持官方要求的角色交替，原生数据不改动。

官方导入器允许并跳过可选的 `user.json` 条目。本应用在该条目保存带明确版本标识的原生备份扩展，
不保存用户账号资料或 API Key。重新导入 SimpleChat 时优先恢复该扩展，保留原消息 ID、分支选择、
完整文本附件、模型、引用、时间线、错误信息和预设；扩展损坏时报告错误，不静默退化为有损恢复。
旧 JSON 与 ZIP 继续沿用原格式和流式导入路径。

导出仍使用数据库快照、逐消息读取、分块 JSON 写入和流式 ZIP。
归档同时保存兼容视图和原生扩展，文件体积可能大于只含官方字段的导出。
压缩摘要、API 配置、未发送草稿和远端文件原件延续原备份的范围限制，不属于此兼容扩展的新增恢复内容。

## Markdown 与选字

行内公式通过原生 `InlineTextContent` 参与 Markdown 段落布局，保留引用、列表、加粗、链接与标点。
显式 `$$…$$`、`\[…\]` 继续按行间公式处理。代码与转义美元符号不参与公式解析。
引用仅保留段落间距，取消文字尺寸动画，避免公式改变段高时短暂裁切。
图片分享沿用同一套行内公式组合方式。

双击入口仅用于可操作的 AI 回复。普通文字优先按已有文字布局定位词边界，再调用 Compose 原生选区 API；
未捕获布局的内容保留原有长按回退。长按菜单仍可进入选字，选区继续由 Compose 管理。
分页页码使用可保存状态，退出选字或离开视口后仍可恢复。

## 验证边界

- 本轮没有使用真实服务密钥，也没有上传用户会话。线上权限、计费、真实超长会话摘要质量和网络耗时尚未实测。
- DeepSeek 兼容性以公开 chat-demo v3 格式和校验器为依据，未验证官方移动客户端是否提供导入入口。
- DeepSeek 官方导入器受 ZIP32 限制；超过其格式容量的归档应继续使用原生备份。
- 独立文件服务和聊天服务必须支持相同的文件引用协议；文件 ID 不能跨服务使用。
- 没有完整本地正文的远程文件不会被静默压缩。提示列出相关文件，保留原摘要与消息。
- 设备验收覆盖当前 Android 模拟器；多厂商真机和旧 Android 仍需后续回归。

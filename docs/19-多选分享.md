# 多选分享

## 使用

长按已完成的消息 →「分享」→ 勾选问答组。

- 一条用户消息及其后续 AI 回复属于同一组；点击组内任一消息一起勾选或取消。
- 顶部支持全选/取消全选，并预留系统状态栏安全间距；底部显示已选组数。空选时禁用导出操作。
- 正在生成的组暂不可选；切换会话退出分享，当前分支变化时移除失效选项。
- 滚动不改变勾选；多选期间点击正文、图片或代码控件只切换勾选，不进入编辑或打开链接。
- 关闭或返回恢复聊天输入区，保留未发送草稿。

分享方式包括本地图片、Markdown、文本和 Android 系统分享。

## 输出

| 入口 | 行为 |
| --- | --- |
| 生成图片 | 在图片选项中选择「长截图」或「分页图片」，再设置是否隐藏名称和思考内容；生成后预览 PNG，可保存到选定目录或通过系统分享 |
| 导出 MD | 系统文件选择器选择保存位置，写入完整 Markdown 文稿 |
| 复制文本 | 按对话顺序复制所选组的正文及文本附件 |
| 更多分享 | 将 Markdown 文件交给 Android 系统分享面板 |

输出仅包含当前分支所选组的内容，不带模型配置、错误记录或其他消息。Markdown 与文本始终只包含正文和附件信息，不带思考内容。导出开始时取得固定快照，后续流式更新不会改变正在生成的文件。

图片宽 1080 px。默认「长截图」尽量合并为一张，高度上限按设备内存预算计算，最高 12000 px；超过上限时自动改用「分页图片」，从头按正常分页规则输出，每张高度不超过 2400 px。两种形式都保留完整内容，遵循相同的表格行和公式分页规则。长图预览按可见区域读取图片，不重复加载整张长位图。

正文复用聊天页的 Compose Markdown 渲染器，公式复用同一 LaTeX 测量和绘制引擎，并在捕获前加载完整 KaTeX 字体。支持完整表格、单元格内公式、分式、根式、积分、求和、矩阵，以及原有正文、代码块和本地图片附件。

图片中用户正文使用右对齐、随文字宽度收缩的气泡，最大占正文区域约 80%，气泡颜色沿用设置的主题色（白底导出的浅色配色）。隐藏“我 / AI”角色标题，回复直接显示正文；Markdown 和文本导出的角色标记继续保留。

同一张圆角选项卡内可勾选「隐藏 SimpleChat 名称」，移除顶部品牌名及底部品牌/页码行，保留对话标题。「隐藏思考内容」每次打开时默认勾选；取消勾选并生成才会将 AI 思考写入图片。思考内容使用较小字号和次要文字颜色，与正文左对齐。存在有效的时间线思考块时按块顺序导出，不重复追加旧版思考字段；没有有效思考块则使用旧版字段。工具记录及思考签名不导出。长截图自动回退分页时保留两个选项。

宽表格会整体适配图片宽度，所有列均参与导出；长表格按完整行分组，跨页重复表头并保持列宽。公式作为整体放置，剩余空间不足时移到下一页，超高的单行表格或公式会整体缩放。普通正文在原生排版的行间空白处分页，避免切断字符。代码块在导出时完整展开、长行换行。

导出使用不绘制屏幕内容的独立 Compose 容器，每次仅记录一个有限高度的图像片段，随后合成页面并写盘；不生成无限高的整篇位图。取消或完成后释放组合与容器。最多处理 20 万字符、80 页，超过时明确提示改用 Markdown，不截断内容。LaTeX 语法本身不受当前引擎支持时，沿用聊天页的兼容源码回退。

Mermaid 在图片导出中保留代码，避免依赖异步 WebView 截取；本轮完善的是原生表格和数学公式。

Markdown 保留完整正文语法和文本附件，图片附件记录名称、不内嵌图片数据。超过 10 万字符的内容不塞入系统剪贴板，提示使用 Markdown。

分享文件位于 `cacheDir/shares`，用 FileProvider 授予接收应用临时读取权限。保留至少 24 小时供接收应用读取，下次生成时清理过期目录；不暴露数据库或其他私有文件。不新增媒体读取/存储权限。

## 验证

构建号 27 更新气泡样式、主题色和隐藏名称选项，并修复选择模式下松手即停止滚动的问题。最新验证结果见 [构建号 27 验收记录](21-构建号27验收-2026-11-18.md)；下列结果为此前功能验收记录。

- `MessageShareTest`：分组顺序、连续回复、未完成组排除、全选与失效选项清理、导出范围、文本附件围栏、超长 Markdown、图片代码块解析。
- 本次新增回归用例：图片思考默认隐藏，取消后重新打开仍默认隐藏；主动取消勾选后可预览，PNG 验证时间线与旧版思考不重复。单元用例覆盖时间线顺序和空思考回退。
- `MessageShareRegression`：真实 ChatScreen 上进入多选、问题/回复联动、全选/取消、滚动、草稿隐藏与恢复、复制与 MD 保存、系统分享 content URI 与只读授权、图片预览、退出后长按菜单恢复、长文 6 页 PNG 与多图授权。
- `NativeShareRenderRegression`：字体加载完成后的非空分式图像、六列宽表格（含公式单元格）、积分/求和/矩阵、70 行表格的完整分页；导出首尾页均做视觉核验。
- 两种图片模式：同一份 70 行表格分页导出为 6 张，长截图合并为 1 张；180 行表格超过长图上限后自动切换为 15 张标准分页图。取消生成释放捕获容器；引用竖线不阻止正文按行间空白分页。
- 复跑 `TextSelectionRegression`，覆盖上一轮选字修复。
- 多选交互已在 Android 14 / API 34 验证；原生表格与公式导出在独立 Android 10 / API 29 模拟器验证（Android 14 也通过了分式与混合文档捕获，长表格测试被外部卸载调试应用中断）。其他系统版本尚未逐一实测。

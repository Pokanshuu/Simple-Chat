# 独立工具 API 与长文本文件传输

适用版本：GitHub 预发布版 v1.1.6，构建号 28。更新日期：2026-11-18。

“设置 > API 配置”是统一的二级页面，上方管理聊天配置，下方显示当前配置的独立搜索与文件 API 状态。点配置行只切换当前配置，不离开此页；点铅笔进入对应配置的三级编辑页，不会激活它，名称可通过“重命名配置”一行修改。

工具参数按当前聊天配置分别保存，不会应用到其他配置。工具编辑页没有“保存”按钮：点顶栏返回或使用系统返回，校验通过后保存并回到 API 页；校验失败时留在编辑页并显示错误，修正后再返回。

## 配置搜索与网页读取

1. 打开“设置 > API 配置”，在“独立工具 API”区选择“搜索与网页读取 API”。
2. 启用独立接口。填写服务地址，或留空以使用当前聊天地址。
3. 选择复用聊天 API Key，或填写独立密钥。确认目标服务支持该密钥。
4. 按服务文档设置接口路径和结果数量。DeepSeek 默认路径分别为
   `/v1/tools/search` 和 `/v1/tools/fetch`，结果数量默认为 5。
5. 返回 API 页以保存配置，然后在聊天输入面板开启联网搜索。

启用独立搜索后，客户端先获取资料，再交给当前聊天模型生成回答。支持 OpenAI 和 Anthropic 聊天通道，
聊天服务与搜索服务可以不同。问题中的网页链接最多读取两条。搜索来源保存在回复时间线中，重开对话后仍可查看。
独立接口使用 DeepSeek JSON 协议，其他服务须提供相同的请求和响应结构；自定义 URL 不代表兼容所有搜索协议。

未启用独立搜索时，DeepSeek 扩展通道继续使用服务端网页工具。搜索与读取可能单独计费。

## 配置文件传输

1. 打开“设置 > API 配置”，在“独立工具 API”区选择“文件 API”并启用接口。
2. 配置文件服务地址和密钥，默认路径为 `/files`。
3. 确保文件和聊天使用相同服务、相同账号。DeepSeek 使用 `deepseek-flash`。
4. 选择“仅识别文字”或“识别文字和插图”。文本、表格和电子书自动使用 `user_data`。
5. 设置长文本阈值，默认为 16,000 字符，可设置为 4,000–1,000,000 字符。
6. 返回 API 页以保存配置。

启用后，文件选择器上传原文件并保存文件 ID，避免将 PDF 转成多张图片后在每轮请求中重复编码。
支持服务端能够解析的 PDF、Word、PowerPoint、表格、电子书和文本。图片选择器继续使用本地图片压缩。
上传和解析期间显示加载提示。接口使用 multipart 上传，`purpose` 位于 `file` 之前。

超过阈值的用户输入和本地文本附件在发送前转为 UTF-8 文件。原始消息保存在本地，
请求中替换为文件引用。内容未变化时复用文件 ID，进程重启后仍可命中磁盘缓存；
修改文本或切换密钥、接口后使用独立缓存。缓存只保存文件 ID 和内容指纹，24 小时后重新上传。
助手历史保留原角色与文本，不转换为用户文件。

文本、表格和电子书上传上限为 32 MiB；需要解析的文档上限为 100 MiB。
文件选择器中的原始图片使用 `user_data` 时上限为 64 MiB。上传从临时文件流式发送，
不把整个大文件读入内存。临时文件在完成、失败或取消后清理。

## 性能与限制

- 文件引用减少重复上传、JSON 组装和传输体积。它不会减少服务端读取文件内容所需的上下文和输入 token。
- 文件 ID 与服务和账号相关。切换密钥后保守地阻止旧引用；同一账号的不同 Key 也需要重新上传。
- DeepSeek 文档引用仍受单请求最多 20 份、解析文本合计最多 8 MiB 等服务端限制约束。
- 服务端保留上传文件。取消等待不保证取消服务端解析；本地删除对话不会删除远程文件。
- 小于 1,000,000 字节的 UTF-8 文本文件同时保留本地正文以供压缩。
  纯远程 PDF、超大文件等没有本地可读取正文时，压缩会给出提示并保留原摘要，不会把文件当作空内容。
- 远程文件原件与解析结果不包含在本地备份中。恢复备份后需要原服务与账号可用；失效时请重新选择文件。
- 自定义文件服务必须兼容 DeepSeek/OpenAI 形状的 Files API，并且聊天端支持相应的文件块。

## API Guide 对齐范围

| 指南能力 | v1.1.6 状态 |
|---|---|
| Search / Fetch | 新增独立配置、查询、网页读取、来源保留 |
| Files / File Parsing | 新增上传、解析 purpose、OpenAI 与 Anthropic 文件引用 |
| 长文本传输 | 新增阈值与磁盘文件 ID 缓存，保留本地原文 |
| Thinking Mode | 保留开关与现有档位，补齐 Anthropic `output_config.effort` |
| 多轮对话、上下文缓存、Vision | 沿用现有实现 |
| 网页工具、标题、用户提醒、TTS | 沿用现有实现 |
| JSON Output、FIM、客户端函数调用、Responses | 本版未新增；不将其表述为已全面支持 |
| 独立 OCR、ASR、远程文件列表与删除 | 本版未提供管理界面 |

## 错误与处理

| 现象 | 处理方式 |
|---|---|
| 401、密钥无效 | 检查独立密钥或复用设置，确认目标服务接受该 Key |
| 402 | 检查服务商余额或额度 |
| 400、422 | 检查模型、路径、文件格式和解析方式 |
| 文件不存在、过期、账号不匹配 | 切回原配置，或移除附件后重新上传 |
| 文件格式不支持或受密码保护 | 移除密码，或转换为 PDF、DOCX、纯文本 |
| 408、429、服务繁忙 | 等待后重试，减少并发上传 |

中文界面显示中文处理建议，英文界面使用对应英文资源。HTTP 错误不会再次套用服务端错误翻译，
避免出现重复嵌套文案。

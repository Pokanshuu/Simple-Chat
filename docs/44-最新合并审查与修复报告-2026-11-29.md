## 6. 未修复 / 建议排期

**P1（建议下一版前处理）**

1. **收藏跳转没有处理回收站/已删除会话**：`RootScreen.onOpen` 只按会话存在与否分支；`ChatDao.findById` 不过滤 `deletedAt`，点进回收站会话还能继续发消息，15 天清理后被静默丢弃。设计要求三分支（恢复并打开 / 去回收站 / 只读复制），见 §48.7.1。
2. **备份把收藏图片全部 base64 常驻内存**（`ChatRepository.favoriteBackupData` + `OwnBackupStream.open`），与 §48.13.4「逐张 materialize、不整批读进内存」相反；大图库导出/恢复有 OOM 风险。
3. **收藏导入无逐条容错**：`favoriteFolders/favorites` 整段 `decodeFromString`，一条坏记录会让整次恢复失败；`importFavorites` 异常时留下半写入且没有报告（§48.11 要求逐条跳过并计入 failures）。

**P2（可排入后续迭代）**

4. 同名新命名（RENAME）恢复时收藏的 `conversationId/messageId` 不重映射；备份夹缺失/重名不校验收敛到默认夹；重复恢复的文件登记冲突会泄漏图片文件。
5. 收藏列表 `SELECT *` 读 `content/attachments` 大字段，且 `ChatViewModel` 与 `FavoritesViewModel` 各自订阅 3 条 Flow；搜索态未按 §48.4.6 平铺、无命中片段、200 条上限无提示。
6. 分享导出未跟随壁纸的画面调节（brightness/contrast/flip/模糊档插值/acrylic tint），`docs/38 §49.6.3` 承诺未完全兑现；120 MB 体积预算与提示未实现。
7. 应用内更新的来源校验：下载 URL/重定向无 host 白名单，安装前未校验包名与签名证书（sha256 与 URL 同源，只能防传输损坏）；错误提示是双语混排的原始异常文本。
8. 多选批量加夹一次事务一个收藏（N 次写）；收藏面板空选中取消收藏的文案/确认流待产品确认。

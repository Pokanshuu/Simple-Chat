# 首次启动引导与思考强度

## 首次启动流程

首次安装时，应用依次展示欢迎页、DeepSeek API Key、模型选择（仅 Key 验证成功后）、备份导入和主题色选择。页面按 8 dp 网格排布，步骤之间使用水平滑动过渡。

API Key 通过 DeepSeek 官方 `/models` 接口验证。只有验证成功后才进入模型页，密钥在用户完成引导时通过现有 `SecretBox` 加密保存。用户可以跳过 Key，稍后在设置中配置其他服务商。

备份选择复用系统文件选择器及仓库现有的流式 ZIP 解析、三种导入方式和进度回调。导入失败会留在引导中并显示错误，用户仍可跳过。主题色直接使用应用已有的七色调色板。

引导完成标记存放在设置 DataStore。启动时自动写入的默认 API 配置不代表引导已完成；未完成就退出，下次启动仍显示引导。已有设置的升级安装不会被重新引导；卸载重装或清除应用数据会重置标记。

## 思考强度

思考滑块现在是关闭、`low`、`high`、`max` 四档。非关闭档位继续通过 `reasoning_effort` 发送。OpenAI 兼容请求及 DeepSeek Anthropic 扩展请求共用同一档位状态；关闭思考时仍按原协议发送关闭状态并省略强度。

## 验收范围

- 首次安装：欢迎页、稍后配置、错误 Key、有效 Key、模型选择、导入成功/失败/跳过、主题选择与完成后重启。
- 升级安装：已有配置不进入引导，API 配置和数据保持可用。
- 思考强度：两种协议均核对 `low`、`high`、`max` 和关闭状态的请求字段。
- 布局：窄屏、系统字号放大、明暗主题与中英文界面。

# v1.2.3-beta.1 预发布验收

日期：2026-11-20。版本：1.2.3-beta.1。构建号：39（替换 38）。渠道：GitHub Pre-release。

## 目标

发布 DeepSeek 兼容性、大请求恢复、文本复制、顶栏回顶、输入框语音状态和缓存用量修复；本次覆盖同名预发布，修复 API Key 错误提示和深色模式文字颜色。

## 变更

| 区域 | 结果 |
|---|---|
| DeepSeek API | 按 Flash/Pro 与 OpenAI、Responses、Anthropic 端点分别处理能力、工具和参数 |
| 大请求 | 上传开始后不自动重放超大请求；错误提示说明断开发生阶段 |
| 文本选择 | 移除格式标记，保留段落空行；列表统一为“· ”并保留嵌套层级 |
| 对话操作 | 双击顶栏滚到顶部；输入框聚焦时关闭按住说话并显示“发消息” |
| 缓存统计 | 解析 DeepSeek 与 OpenAI 的缓存 token 字段；请求间不沿用旧用量 |
| 文案与深色模式 | 明确无效 Key 时只显示 Key 错误；全局默认文字颜色跟随主题 |

# 字体主题与壁纸设计方案

## 入口与信息架构

将「设置 → 外观 → 自定义主题与壁纸」更名为「字体主题与壁纸」，向用户开放字体、颜色和字号调整。原有主题、界面和壁纸编辑入口继续在同一编辑器内。新增一级选项卡「文字」，并将外观页原有的「文字大小」「自定义字体」入口并入其中，统一编辑和保存。

```text
设置 → 外观 → 字体主题与壁纸 → 文字
                               ├─ 文字大小
                               ├─ 气泡文字
                               ├─ 回复文字
                               └─ 界面文字
```

| 子选项卡 | 控件 | 生效范围 |
| --- | --- | --- |
| 文字大小 | 跟随系统、现有全局文字大小档位 | 所有跟随全局的类别 |
| 气泡文字 | 字体、「使用主题色」、「自定义颜色」、HSL 滑块、折叠的高级选项 | 用户已发送的气泡正文及其展开状态 |
| 回复文字 | 字体、「自定义颜色」、HSL 滑块、折叠的高级选项 | 助手正文及 Markdown 标题、列表、引用和表格中的文字 |
| 界面文字 | 字体、「自定义颜色」、HSL 滑块、折叠的高级选项 | 顶栏、设置、菜单、按钮、输入框等界面文字 |

回复中的代码和 LaTeX 沿用等宽字体和数学字体，随回复字号调整。思考面板保留次要文字层级，链接、错误提示等保留用于区分状态的颜色。

## 字体、颜色和预览

三个类别使用一致的编辑方式。每页先展示字体选择，列表旁用「＋」打开现有字体导入流程，共用设备上的字体库。导入成功后在当前类别选中新字体，其他类别保持现有选择。字体文件缺失、删除或缺字时回退系统字体。每类可以恢复默认字体和主题配色。

「气泡文字」「回复文字」「界面文字」的「自定义颜色」默认关闭。开启后，该类别的 HSL 滑块才可编辑，并立即预览自定义色。首次开启时用当前实际文字色初始化。浅色和深色各保存一份，切换预览时编辑对应配色。关闭自定义颜色后保留上次的 HSL 值，再开启时恢复。

| 类别与状态 | 实际文字色 | 控件 |
| --- | --- | --- |
| 气泡文字，自定义关闭、使用主题色关闭 | 当前主题默认的气泡文字色 | 「使用主题色」可切换，HSL 置灰 |
| 气泡文字，自定义关闭、使用主题色开启 | 当前主题的主题色 | 「使用主题色」可切换，HSL 置灰 |
| 气泡文字，自定义开启 | 当前明暗模式的 HSL 自定义色 | 「使用主题色」置灰，HSL 可编辑 |
| 回复文字或界面文字，自定义关闭 | 当前主题中该类别的默认文字色 | HSL 置灰 |
| 回复文字或界面文字，自定义开启 | 当前明暗模式的 HSL 自定义色 | HSL 可编辑 |

气泡文字开启自定义颜色时保留「使用主题色」原值。关闭自定义颜色后恢复该开关的操作，并立即按保留值显示主题色或默认气泡文字色。「使用主题色」仅控制气泡文字的前景色。预览使用实际气泡、回复、界面与壁纸背景。界面次级文字与占位符从有效界面文字色派生，维持原有层级。

高级选项默认折叠，展开后显示「单独调整文字大小」以及该类别的字号控件。字号开关只控制大小，字体与颜色各自独立生效。预览随编辑即时更新，通过现有编辑器的保存操作应用。

## 全局字号与类别覆盖

| 状态 | 类别实际字号 | 「文字大小」子页 |
| --- | --- | --- |
| 三类开关均关闭 | 三类都使用全局设置 | 全局控制可编辑 |
| 一类或两类开启 | 开启的类别使用自己的字号，其余类别使用已保存的全局设置 | 全局字号和「跟随系统」控制置灰，显示当前采用独立字号的类别 |
| 三类均开启 | 各自使用独立字号 | 全局控制置灰 |

首次开启独立字号时，用该类别当前有效字号初始化，避免开关一开文字就跳变。关闭后立即跟随全局，同时保留上次独立值，再开启时恢复。最后一个独立开关关闭后，全局控件恢复可编辑。全局之前若处于「跟随系统」，系统字号变化仍可影响继承类别。独立字号覆盖应用内全局档位，同时保留 Android 的无障碍字体缩放，避免把系统缩放重复计算。

## 字号与行距

每类通过同一套排版规则解析字体、字号和行高。字号变化时，按各样式原有的字号与行高比例同步调整，保留正文、标题和标签之间的层级。计算行高时以字体实际度量和回退字体所需空间为下限，确保中文、英文、上下标、分式及混排行都能完整容纳。对行内公式应允许实际占位高度撑开行框，回复的流式与静态显示使用同一套有效样式。

预览应覆盖中文长段、英文长词、连续多行、标题、列表和带分式的回复。聊天正文、气泡折叠展开、输入框和设置行都要检查换行、触控区域、文字裁切和相邻行重叠。分享图片使用与对话一致的有效气泡和回复样式。

## 设置迁移与验收

- [x] 迁移现有三类字体选择和全局字号设置。旧安装首次打开时保持原有效果；独立字号覆盖与三类自定义颜色均默认关闭。旧设置缺少新配置时解码到兼容默认值。
- [x] 复用现有字体导入和私有字体库；编辑器可通过「＋」导入字体，并可进入字体管理、删除字体和清理引用。
- [x] 三类文字自定义颜色默认关闭，打开后启用 HSL；浅色/深色分别保存。气泡主题色开关在自定义颜色打开时置灰，关闭自定义后恢复；两组配置值均保留。
- [x] 全局和单类字号覆盖按设计规则持久化：任一覆盖开启时禁用全局字号控件，非覆盖类别继续使用原全局字号；关闭覆盖后回到全局值并保留自己的字号值。
- [x] 字体、字号、颜色实时应用于聊天和分享图片；预览可在浅色/深色间切换并展示气泡、回复、界面文字与公式。
- [ ] 真机目视复验默认/放大系统字号、长文本换行、壁纸对比度、行高和控件点击；构建通过不能替代不同字体和设备上的视觉核对。

# v1.2.3-beta.3 验收记录

日期：2026-11-20。版本：1.2.3-beta.3，构建号 42。发布类型：GitHub Pre-release，不附 APK。

## 本次变更

- 已发送请求共用互斥保护；重复续写或重新生成不会启动第二个请求。
- 编辑压缩摘要覆盖范围内的消息时，先失效旧摘要与检查点，再保存编辑。
- 请求体开始写出后不再自动重放；SSE 错误事件会终止读取。
- 模型列表刷新无论正常返回或遇到异常，均清除加载状态。

## 长上下文跨路由验收范围

沿用 beta.2 真实端点验收：Android 模拟器使用真实 ChatViewModel、Room 历史、请求组装与 SSE，单一 20 轮合成对话约 27 万输入 token。OpenAI 兼容与 Anthropic 兼容端点分别通过 Flash → Pro → Flash；Anthropic 会话另切换到 OpenAI 兼容端点并以 Pro 继续。每轮均完整发送文字历史并取回首条校验码，服务端返回 HTTP 200。历史记录另覆盖约 259K 输入 token 的双端点 Flash → Pro → Flash。

模型能力变更时，历史工具块、图片与远端文件引用按新端点能力选择发送或跳过；可选工具/附件拒绝时的纯文字降级以及上下文超限压缩由模拟测试覆盖。真实长上下文验收没有覆盖网络断开和 Content Exists Risk，不将其记作真实端点实测通过。

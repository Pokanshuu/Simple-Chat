## 3. 分享截图补齐项

- 品牌行：`ShareBrandRow` 用 Compose 的 `AppIcons.SimpleCat` + UI 字体渲染，一次 `measure`/`capture`，每页 `drawBitmap`；隐藏名称时整行跳过；捕获失败退回纯文字品牌行。
- 标题 / 页脚：通过 `createFontFamilyResolver` 把 UI FontFamily 解析为 `Typeface`；失败回落 `sans-serif-medium` / `sans-serif`。
- 壁纸：`ShareImageStyle.wallpaper` 进入渲染；`drawWallpaper` 平铺 + 保护层 + dim；预览标题在生成后加「含壁纸」；壁纸文件缺失时面板显示提示，导出继续纯色。
- 隐私：复选框常驻、副标题说明壁纸会带出、预览标注；无新增权限，文件仍写 `cacheDir/shares`。

## 5. 明确保留的差异 / 后续项

1. 收藏页顶部使用「文件夹胶囊」而不是设计草图里的「全部 / 我 / AI 角色胶囊」：当前产品更常用按文件夹筛选，角色信息放在行首；分组模式另行提供。
2. 收藏夹管理是对话框形态，未拆成独立二级页面；功能（新建 / 重命名 / 删除 / 条数）已对齐，视觉上少一次页面跳转。
3. 多选未提供「导出 Markdown / 图片」：§48.15.1 MVP 已明确不含导出；取消收藏与批量加夹已实现。
4. 缩略图全屏查看依赖收藏里保存的图片；纯文本附件按设计只保留文件名，不提供查看器。
5. 分享截图的深色 + 壁纸 + 1.3× 字号矩阵仍建议真机复验；代码路径已接通，但不同主题色下的壁纸对比度按 §49.6.8 接受「不保证」。
6. 无障碍目前覆盖按钮 / 行点击 / 勾选 stateDescription 与 onClickLabel；TalkBack 全量朗读仍需设备复验。
7. 图片、纯文本附件、搜索命中片段与备份完整往返当前由 JVM 纯函数测试覆盖；带真实图片的收藏仍需在有图库里复验。

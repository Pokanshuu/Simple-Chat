## v1.2.3-beta.1（构建号 39，2026-11-20，预发布；替换构建号 38）

- **DeepSeek 模型能力**　按 Flash、Pro 和兼容端点分别处理搜索、读链接、标题、思考参数与历史消息，避免把一种接口的能力误发到另一种接口。
- **大请求恢复**　请求体超过 1 MiB 后，上传一旦开始便不自动重放断线请求，降低服务端已处理但客户端重复提交的风险。错误提示会区分“未收到响应头”和“收到响应后未收到回复”。
- **文本复制**　选择回复时移除 HTML/Markdown 格式标记，保留段落空行；无序列表统一为“· ”，并保留嵌套缩进。
- **对话操作**　双击顶栏返回对话顶部。输入框获得焦点时关闭按住说话入口，并显示“发消息”。
- **缓存用量**　识别 DeepSeek 与 OpenAI 格式的缓存 token 字段；每次新请求从独立用量状态开始，避免沿用上一轮数字。
- **错误与深色模式**　无效 API Key 只显示对应错误；未指定颜色的文案跟随主题，深色模式下保持可读。
- 本构建替换同名预发布的构建号 38；旧提交 `ef88782ad38451c390586f41cddb72f66c997aa0`，旧 APK SHA-256 `4588c49954d814f1c7b15365c0161c16a2912a33d571cf07aa641c5e00657cc8`。

**兼容性说明**　DeepSeek 的多种兼容端点在模型能力、请求参数和 usage 字段上并不完全一致；“兼容”二字这次确实承担了不少工作。应用按端点分别处理这些差异。

安装包和校验值见 [v1.2.3-beta.1 预发布说明](../release-notes/RELEASE_NOTES_v1.2.3-beta.1.md)。

正式版。变更相对于 v1.1.5。安装包和校验值见 [v1.2.0 发布说明](../release-notes/RELEASE_NOTES_v1.2.0.md)。

### 新增功能

- 首次打开应用时，可验证 DeepSeek API Key、选择 Pro 或 Flash、导入备份并设置主题色。可跳过 API 配置和备份导入。应用会加密保存 API Key，已有设置的用户升级时会直接进入聊天。
- 在每份聊天配置中独立设置搜索、网页读取和文件 API。支持 DeepSeek Search、Fetch 和 Files，可复用聊天密钥或为工具配置单独的密钥。
- 新增 `low` 思考强度，支持 DeepSeek 的 OpenAI 和 Anthropic 兼容端点。
- 支持导出 DeepSeek v3 兼容 ZIP。备份包含 SimpleChat 扩展，用于保留分支、预设、来源和本地附件正文。原有 JSON 和 ZIP 备份仍可使用。
- 双击 AI 回复即可选择、复制文字。也可从长按菜单进入选字。

### 改进

- 启用文件 API 后，长输入和文本附件可通过文件引用发送。重复使用同一份内容时，应用会复用已上传的文件 ID。
- 上下文压缩会根据内容选择摘要重点。预算允许时一次总结待压缩历史，必要时分批处理。中断后可从匹配的进度继续。
- 改善 Markdown 和 LaTeX 混排效果，让行内公式与正文保持连贯，并将同样的排版用于图片分享。
- 图片导出默认隐藏思考内容。选择包含思考内容时，通过字号和文字颜色区分思考与正文，移除“深度思考”标题和左侧竖线。
- 为密钥验证、文件格式、上传超时和文件引用失效提供中文提示及处理建议。

### 修复

- 修复 DeepSeek Anthropic 兼容端点发送长文本时的问题。
- 如果远程附件缺少可读正文，压缩前会提示文件名并保留原摘要。
- 修复公式裁切、引用段落间距、编辑后显示旧正文，以及退出选字后页码未恢复的问题。

### 使用限制

- 文件引用可减少请求体积。文件正文仍计入模型上下文和输入 token。文件 API 和聊天 API 须使用同一服务和账户。
- 备份不包含仅存于服务端的文件原件。需要恢复这类附件时，请保留原文件。

- 为系统提示、输入和输出预留预算；服务端拒绝输入大小时自动缩小批次，保留模型原有的上下文配置。

- 修改消息、切换分支或发送新消息时停止正在进行的压缩，避免应用过期结果。
- 压缩前列出没有完整可读正文的附件，避免遗漏文件内容；失败时保留原摘要。
- 修正公式段落裁切、引用段落间距和退出选字后的分页状态恢复。
- 修正静态 Markdown 在编辑或换页后继续显示旧正文的问题。

### 新增功能

- 按问答组多选分享，支持长截图、分页图片、Markdown、复制文本和系统分享。
- 图片导出支持原生表格和数学公式；宽表格适配页面，长表格按行分页并重复表头。
- 相册和文件选择器支持多选；逐项导入并汇总失败项。
- 搜索设置支持包含或排除非当前分支。

### 改进

- 长请求提供准确的请求体长度；达到 1 MiB 时，上传写超时由 30 秒延长至 120 秒。
- 发送前校验估算上下文和回复预算；大请求中断或返回无法识别具体原因的 5xx 时显示压缩指引。
- 上下文按批压缩，支持超大正文、文本附件和已有摘要。失败、取消或输出截断时保留原摘要。
- 设置按账户、个性化、对话和数据管理组织；外观与对话行为使用独立页面。
- 单行条目最小高度统一为 46 dp，上下内边距为 12 dp，行首图标为 18 dp。

### 修复

- 文本选区在滚动、离屏恢复和其他回复更新时保持；退出轻点不会触发其他操作。
- 选择态保留消息分页和代码块展开状态；长用户消息的分块文本按顺序复制。
- 未收到正常结束信号的响应按中断处理，避免保存不完整摘要。

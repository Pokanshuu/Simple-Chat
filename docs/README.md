## 当前版本与历史记录

当前发布版本为 v1.1.5 / versionCode 22，发布说明见 [`../RELEASE_NOTES_v1.1.5.md`](../RELEASE_NOTES_v1.1.5.md)。01–11 保留设计演进与历史验证记录，旧版本、环境和测试计数不代表当前发布状态；12 为 2026-11-16 的审查快照，13–15 记录后续新增功能与真机反馈修复。当前实现、迁移 schema 与构建配置应结合源码核对。

公开前已检查文档中的凭据、个人路径及对话示例，示例已匿名化；真实聊天、测试归档、签名密钥和本机恢复资料不纳入仓库。

## 维护约定

- **改设计先改这里**：文档是设计的唯一来源，代码与当前设计不一致时应核实并同步修正，历史记录不作为覆盖当前实现的依据。
- **章节编号只增不改**：新增内容追加新编号，避免让既有的「见 §xx」失效。
- **不放进仓库**：真机截图、参考 APK、测试素材、构建产物均不入库（见根 `.gitignore`）。
- **文件名**：两位数字前缀保证排序 = 推荐阅读顺序；分类名用中文。

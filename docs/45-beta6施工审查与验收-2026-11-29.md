| 设计条目 | 实现 | 结论 |
|---|---|---|
| 分层：网络 / 编排 / 数据分开 | `net/WebDavClient` + `net/WebDavXml`（纯函数）、`data/sync` 计划器/状态/协调器 | ✅ |

| 身份按会话 id（不按标题） | 新增 `ImportMode.SYNC_APPLY`，只按 id 替换，保留草稿与收藏指针 | ✅ |
| 删除传播 | 墓碑先到：本机未改则删、改过则保留本机并回传（冲突记录）；回收站不参与同步 | ✅ |

### 1.3 滚动条与胶囊（docs/41）

| 设计条目 | 实现 | 结论 |
|---|---|---|
| Thin（3dp）→ Ready（6dp，滚动 ≥150ms） | 已实现，停手 700/900ms 后淡出 200ms | ✅ |
| Ready 态右侧 32dp 命中带；轨道点击跳转 | 已实现；长按让位消息菜单；横向位移让位 | ✅ |
| 拖动 O(1) 定位，禁止 `scrollBy(超大值)` | `collectLatest + scrollToItem`，拖动开始即取消惯性 | ✅ |
| 胶囊：首行前 13 码点、跟随滑块 | 已实现（Markdown 标记清洗、emoji 安全截断、tooltip 配色） | ✅ |
| 与选择文本 / 分享多选 / 索引面板的互斥 | 三者激活时禁用滚动条手势 | ✅（审查后补） |
| 性能：拖动不逐帧重组 | 状态在绘制期读；文本仅在目标行变化时更新 | ✅ |
| 偏差 | 未做胶囊预览的 LRU 缓存（现算成本 <0.1ms）；胶囊 RTL 位置未单独验证 | 保留偏差（P2） |

### 1.4 思考展开策略（docs/42）

| 设计条目 | 实现 | 结论 |

| 五档行为矩阵 | 生成中：尾巴 / 全文（分段渲染）；收口后：折叠 / 展开；「展开全部」胶囊（B/C 档） | ✅ |

| 开关默认开、位置在对话行为 | 已实现 | ✅ |
| 偏差 | P1 时间工具（time_now/convert/add）未实现；无秒级、无农历（均为设计 Non-goal/P1） | 保留偏差 |

## 2. 审查后修复

- 同步端点强制 HTTPS（本机回环/模拟器宿主例外）。
- `latestReminder()` 与时间上下文共用同一轮时间基准，避免同轮两个时间来源。
- 分享多选 / 选择文本态下思考标题不再可点（两个面板都加 `toggleEnabled`）。
- 同步错误文案补齐（认证/TLS/配额/超限/非 DAV/冲突/繁忙/网络/HTTPS），中英成对。

## 4. 保留偏差与后续项

1. 云同步 MVP：无后台自动同步（按设计不引 WorkManager）、不同步收藏夹/设置/壁纸、无「删除云端数据」入口；需要真实网盘做双机验收。
2. 同步分片为单会话 JSON：超大附件会话导出/上传耗时较长，进度条已覆盖；后续可评估附件寻址。
3. 滚动条胶囊预览无 LRU 缓存、RTL 位置未单独验证（P2）。
4. 收藏跳转回收站/已删会话的三分支、备份收藏图片整批 base64 内存、收藏导入逐条容错仍在审查报告 `docs/44` §6 的遗留清单里（本版未改）。
5. 时间工具（P1）与同步的收藏/设置（P1）按设计分阶段推进。

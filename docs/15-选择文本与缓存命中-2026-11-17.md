# 选择文本、首字过渡、操作栏与缓存命中

实现日期：2026-11-17。v1.1.5 / versionCode 22 的真机反馈第二轮，接在
[`14-编辑保存与朗读收尾-2026-11-17.md`](14-编辑保存与朗读收尾-2026-11-17.md) 之后。

## 1. 选择文本：不要"模式"，点哪里就从哪里开始选

上一版的做法是"进入选择态 → 界面出现一条提示和「完成」按钮 → 自己再长按起选"。
用户不接受那个中间态：它多了一个按钮、多了一次手动长按。

现在：

- 菜单里点「选择文本」后**没有任何界面元素**出现；
- 选区**立刻**落在刚才长按的位置上（词/片段级别），可以直接拖动拉长、系统工具栏复制；
- **点空白处即退出**（列表空白、其他消息、输入栏都算），不设「完成」按钮。

实现要点（`MessageList.kt`）：

| 问题 | 做法 |
|---|---|
| 怎么"从按下的位置开始选" | Compose 没有"按坐标设置选区"的公开接口（`SelectionState` 只认全局字符偏移，多段文本还要自己累计算长）。改为在同一个点上**合成一次长按**（`startSelectionAt`）：命中测试、行定位、手柄全走系统原本那一条路 |
| 合成的长按会不会被当成"点了一下" | 按住 560ms（> 系统长按阈值 500ms）；同时列表层的"点空白退出"检测带一个空的 `onLongPress`，长按被它消费掉，不会再触发 `onTap` |
| 什么时候注入 | 等两帧 + 90ms：`SelectionContainer` 要挂上去、菜单要收起 |
| 怎么退出 | `selectingId` 抬到列表层，`dismissSelectionOnTap` 挂在 `LazyColumn` 上；滚动也退出（与"碰一下看元信息"同一条即时性规则） |

风险：注入的是本进程内的合成事件，只在真机上验证得准。若某台设备上没生效，
表现只是"进入选择态但没自动选中"，用户仍可长按起选 —— 不崩、不卡。

## 2. 操作栏：刷新键**永远**在行尾

上一版把权重挂在 `AnimatedVisibility` 上：不显示模型信息时它不占位，
刷新键就滑回按钮旁边，表现为"只有显示模型时才居右"。

改为：`Box(Modifier.weight(1f))` 恒定占住中间剩余宽度，元信息（`MessageMetaSlot`）
作为它的内容淡入淡出，刷新键固定跟在 Box 之后 —— 位置与元信息是否可见无关。

## 3. 首 token 等待：「加载中…」过渡

请求发出到第一个 token 之间，界面上原先什么都没有。长上下文 + 思考型模型这一段
可以走十几秒，看起来像"消息没发出去"。

新增 `WaitingIndicator`（`ThinkingHeader.kt`）：一个 15dp 的旋转弧 + 「加载中」，
省略号按秒循环。形状、色值、左缘对齐都与思考栏一致 —— 第一个思考块到达时，
视觉上是同一行在换字，而不是凭空冒出一个控件。

判据：`streaming && 正文空 && 没有思考 && 没有时间线`。任何一块内容出现即让位。

## 4. 缓存命中率

**能拿到。** 两条通道在流里都会回用量，而且客户端本来就已经解析出来了
（`StreamEvent.Usage`），只是此前被丢掉：

| 通道 | 字段 | 含义 |
|---|---|---|
| DeepSeek（OpenAI 兼容） | `usage.prompt_cache_hit_tokens` | 命中前缀缓存的输入 token |
| Anthropic 兼容 | `message_start.usage.cache_read_input_tokens` | 命中缓存的输入 token（`cache_creation_input_tokens` 是写入侧，计入输入总数） |

现在的做法：

- `ChatViewModel.recordUsage()` 收下并**合并**两段上报（Anthropic 的输入侧在
  `message_start`、输出侧在 `message_delta`；缺字段不能把已有值冲成 0）；
- 只保留**最近一次**请求（`lastUsage`）—— 缓存命中率是"这一轮前缀有没有被复用"，
  跨轮平均会把它稀释成一个看不出变化的数字；切换会话时清空；
- 「上下文占用」面板的统计区新增一行 **缓存命中（最近一次）· 命中/输入 · 百分比**；
  服务端没报缓存字段时整行不出现，不显示假的 0%。

若要**跨轮聚合**（整条会话平均命中率），需要给 `messages` 加两列并做一次数据库迁移；
当前版本没做，先把"最近一次"这个最有信息量的数字摆出来。

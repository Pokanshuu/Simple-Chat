# 自动朗读与 API 配置管理

实现日期：2026-11-17。纳入 v1.1.4 / versionCode 17，发布说明见根目录 `RELEASE_NOTES_v1.1.4.md`。

## 自动朗读

- 入口：对话页右上角，新建对话左侧。关闭为静音图标，开启为主题色喇叭，48dp 触控区域与无障碍状态说明。
- 默认关闭；偏好保存在本机，重启和新建对话后保持。
- 仅当前对话中新生成且保存成功的 DONE 回复触发一次。重试或续写成功也属于一次新完成；停止、出错或保存失败不触发。
- 打开历史、切换分支、重新开启开关不会补读旧消息。
- 关闭自动朗读时立即停止当前播放，同时取消仍在等待 TTS 初始化的任务。切换会话、离开页面或退到后台停止播放，不在后台意外出声。
- 使用现有“设置 → 朗读音色”。系统音色依赖设备的 TTS 引擎；已选 DeepSeek 官方音色时使用已有官方 TTS 通道及其配置条件。
- 正文朗读继续略去代码块、表格和 Markdown 标记；不朗读思考过程。
- 系统 TTS 长文按引擎输入上限切块排队，不截断全文，emoji 边界保持完整。每次播放使用独立 token，旧完成回调不能结束新播放。

技术实现：ChatViewModel 仅在实时回复完成并终写成功后通过无 replay 的 SharedFlow 发布 CompletedReply。AutoReadAloudEffect 在 RESUMED 生命周期内收集，并检查当前会话、开关、音色可用性、消息角色及状态。不通过扫描历史列表猜测完成事件。

## API 配置管理

入口：设置 → API → 当前配置。管理页列出配置名称、服务商、模型和地址，点击整行切换，旁边可重命名或删除。

### 保存与切换

- 每份配置独立保存服务商类型、Base URL、模型 ID、协议、模型目录、思考档位、采样参数、输出上限、联网开关与加密 API Key。
- 编辑当前配置后自动保存；切换配置一次性恢复全部字段，不需要重新输入 Key。
- “新建配置”创建空白自定义配置并切换过去；“复制当前配置”将当前整组内容（包含加密 Key）另存后独立编辑。修改副本不影响原配置。
- 服务商选择器作为快捷切换，恢复该服务商最近使用的配置；第一次选择新服务商创建其默认配置，不沿用其他服务商的 Key。
- 删除当前配置会切换到另一份配置；至少保留一份。删除配置不删除会话。
- 现有单配置自动作为第一份配置保留，包括地址、模型与 Key；旧明文 Key 先加密再完成迁移，加密失败保留原配置并报错。
- 配置只在本机保存，API Key 不进入对话 JSON/ZIP 备份。换机仍需重新配置密钥。
- 切换期间尚未返回的模型目录查询带来源配置 ID 与 URL 校验，不能把旧目录写到新配置。

### 存储与一致性

DataStore 新增 api_profiles_v1 与 active_api_profile；配置列表内只存 AES-GCM 密文，不存 Key 明文。活跃配置投影沿用现有字段，保持请求层兼容。配置修改、列表更新、当前 ID 切换都在同一次 DataStore edit 内提交。只解密当前配置的 Key，配置对象 toString 不输出密钥或密文。

同一 DataStore 在进程内共享；测试使用显式注入的独立 DataStore，避免测试配置污染应用状态。损坏配置列表明确失败，不按空列表覆盖原有凭据。

## 验证

- JVM：新完成回复筛选；停止/错误/其他会话不朗读；长文切块无丢字、emoji 不切断；配置序列化独立、日志脱敏、损坏数据拒绝。
- Android：从旧明文配置迁移并验证磁盘文件不含 Key 明文；多份配置切换、复制独立性、重命名、删除与重新读取；旧模型查询结果不能污染当前配置。
- 真实 Compose：点击自动朗读按钮、实时生成完成后调用播放一次、关闭停止、重新开启/历史加载/停止回复不补读；配置列表可显示并选择。
- 回归：20 次发送/停止、30 次快速切换、压缩后发送、写库失败保留草稿等原有设备测试通过。
- 页面测试使用模拟音频输出接收器确认播放/停止调用，未调用用户的付费 API，也不替代不同厂商系统 TTS 引擎的实际音质验证。

## 特殊 LaTeX 排版补充

针对截图中的 `\scalebox` 错误节点增加兼容层。`scalebox`、`resizebox`、`rotatebox`、`raisebox`、`parbox` 和 `makebox` 的尺寸/旋转外壳可在显示时展开，内部文字、数学内容、颜色与边框继续交给原生渲染器。嵌套参数按平衡括号解析，不用正则直接剥括号。

兼容模式优先展示内容，不承诺复现原始缩放、旋转和固定宽度。界面提供“查看原文”；解析错误、未知命令、异常规模或无法安全处理的内容显示完整源码，避免只剩红色命令错误块。数据库、复制、导出与模型请求保留原始文本。

## 搜索显示修正

搜索命中不再切换原文模式，消息始终使用正常的 Markdown、代码和主题配色。根据实际排版的文字范围定位并绘制关键词底色，渐显后短暂停留再渐隐；动画结束不改变展开状态或分页。用户消息保持纯文本样式，深色主题采用对应文字颜色。

Android 34 模拟器验证深浅主题下的普通正文、加粗列表、代码、表格、折叠用户消息和长消息分页；检查命中可见、原文按钮不存在及渐隐后位置稳定。

## v1.1.4 构建 18 补充

历史图片发送使用可重开的输入流进行有界解码，统一生成白底 JPEG；尺寸与文件头不再作为原样发送的充分条件。本地原件和备份内容保持不变。图片跳过计数按请求汇总，横幅中的“不再提醒”位于 × 左侧，偏好全局保存；设置提供恢复开关。

全局搜索按消息返回命中，包含用户/AI 角色、消息时间及同父多版本信息；仅标题命中仍保留结果。预览在 SQLite 中截取，每页 100 条，继续加载可取得剩余结果。输入变化取消旧查询并防抖；扩展当前页时保留已显示列表。

搜索定位使用排版后的关键词路径和窗口坐标，按实测输入区高度计算可阅读区域，将命中置于约 38% 高度。首尾预留空间在渐隐后保留，新增消息或分支变化后释放。表格使用相同 AST 标注器和正常文字绘制回调，保留原有样式并支持高亮。

## v1.1.4 构建 19：搜索导航与状态隔离

搜索结果不沿用抽屉的“当前会话”底色：结果标识消息，不能因为它们属于当前会话而全部显示选中。选中底色改为“会话 ID + 消息 ID”对应的单条结果，返回时保留、点击另一条转移、查询变化清除；仅标题命中使用独立标识。抽屉保留其当前会话状态。

搜索跳转先关闭抽屉再打开目标，保留搜索模式、关键词、加载页与列表状态。对话页在搜索期间暂停自动跟底及输入区高度变化引起的贴底补偿；会话初始定位记住搜索入口，避免高亮结束后丢失定位意图。系统返回和右滑抽屉均回到原搜索页，点击搜索页返回键才退出搜索。

完整 RootScreen 设备回归覆盖：空白对话页进入搜索、键盘展开时点击最终长回复、首次加载、渐隐后位置保持、重复搜索跳转，以及系统返回和右滑恢复关键词/结果/列表位置；独立深浅主题截图另验证初始空闲底色和同一会话仅单条消息选中。

## v1.1.4 构建 20：搜索布局退出与宽表格

此前为首尾命中定位到中间偏上而保留的空间，只在新增消息时释放。构建 20 为恢复跟随增加统一退出路径：清除未完成的定位并重置预留空间，下一帧按正常布局回到底部；发送、重试、重新生成和继续生成也释放预留空间。设备回归先复现约 542dp 的残留间距，修复后量测正文末尾到输入栏的间距，并覆盖搜索后实际点击发送。

表格按列测量可读宽度，不使用百分比 weight 强压入屏幕。每列在 88–320dp 范围内按内容取宽，长单元格继续换行完整显示；表头、正文和分隔线共享同一横向滚动。搜索可通过 BringIntoView 同时定位右侧列。

表格及代码区登记可横滚区域，消息索引按按下落点让位；外层抽屉在同一区域手势期间关闭拖动识别，直至手指抬起。左右边界继续拖动也不转交导航，纵向仍由消息列表处理。完整 RootScreen 设备回归验证双向拖动、边界、纵滑及右侧列搜索。

## 16.1 通知权限：声明了不等于申请

**现象。** 升级到 v1.1.5 的包里，生成期间通知栏没有任何条目；前台服务本身正常：
logcat 里有 `Background started FGS: Allowed [callingPackage: com.simplechat.app; …
intent: cmp=com.simplechat.app/.service.GenerationService]`，说明服务起来了、进程按预期
提了优先级，只是那条「正在生成回复」看不见。

**根因。** `AndroidManifest.xml` 里声明了 `POST_NOTIFICATIONS`，但代码里从来没有
`requestPermission` —— 清单里的声明只是"允许申请"，不申请就永远不弹、也永远拿不到。
实测 `dumpsys package com.simplechat.app`：

```
android.permission.POST_NOTIFICATIONS: granted=false
```

`dumpsys notification` 里 `numEnqueuedByApp=2`、`numPostedByApp=0`：通知确实进了队列，
被系统按权限拦下。Android 13 以下该权限默认授予，所以这个问题只在 13+ 出现。

**修法。** `MainActivity` 里加一个只在 Android 13+ 执行的一次性请求
（`RequestNotificationPermission`）：首帧之后检查权限，未授予就 `launch` 系统对话框；
已经授予的不会再问。拒绝也不影响生成——前台服务照常跑，只是没有那条进度通知，
这正是 `GenerationService` 注释里写的边界。

**验证。** 允许之后立刻重跑一次长回复：通知栏出现「正在生成回复」（静音分组），
生成结束后自动消失；强制停止再启动，不再重复弹窗。

## 16.2 行高网格：一条尺子量所有"一行一条"

**问题。** 抽屉会话行 46dp、长按菜单 46dp、设置里的单行 48–54dp、双行约 70dp、
消息索引 46dp —— 同一块屏幕上五种节奏，没有任何一处说明为什么不同。

**约定。** 在 `ui/common/Controls.kt` 的 `Space` 里定三个数，全局只认这三个：

| token | 值 | 用途 |
|---|---|---|
| `Space.Row` | 40dp | 单行条目最小行高（抽屉、设置、菜单、消息索引） |
| `Space.RowPadY` | 8dp | 单行条目上下内边距 |
| `Space.Icon` / `Space.IconGap` | 18dp / 12dp | 设置页行首图标与图标-文字间距 |

- 单行：`.heightIn(min = Space.Row)` + 上下 `Space.RowPadY`，内容垂直居中；
- 双行（标题 + 说明）：不加固定高度，由内容撑到约 56dp（8 + 22 + 3 + 16 + 8）；
- 分隔线缩进改成 `Space.Screen + Space.Icon + Space.IconGap`（= 46dp），
  以后调图标，线自动跟着走，不会再出现"线在字左边/右边"。

**覆盖范围与实测（Pixel 8 Pro，density 3.0）。**

| 位置 | 改前 | 改后 |
|---|---|---|
| 抽屉会话行 | 46dp（上一轮已收 80%，实际 40.8dp） | 40dp |
| 长按 / 更多菜单 | 46dp 固定 | 40dp |
| 设置单行（入口、开关、链接、信息） | 48–54dp | 41dp |
| 设置双行（标题 + 说明） | 约 70dp | 55dp |
| 消息索引行 | 46dp | 40dp |

**取舍。** 40dp 低于 Material 建议的 48dp 触控目标，换来一屏多两三行；
整行仍然是点击区域，实测点按反馈正常。真要回到 48dp，改 `Space.Row` 一处即可。

**抽屉会话行为什么是 40 而不是 37。** 上一轮先把它从 46dp 收到 80%（36.8dp），
实际渲染 40.8dp；这一轮直接对齐 `Space.Row` = 40dp，视觉几乎不变，
但从此和设置、菜单同一条线。

**输入栏不动。** `InputBar.kt` 本轮零改动；"不影响输入框高度"是硬约束。

## 16.3 产物文件名带版本号

`app/build.gradle.kts` 用 `androidComponents.onVariants` 改输出名：

```kotlin
val appVersionCode = 25
val appVersionName = "1.1.5"
// …
output.outputFileName.set("SimpleChat-$appVersionName-$buildType.apk")
```

- 版本号只写在这一处：`defaultConfig` 与文件名都从这里取，「关于」页读的是
  `BuildConfig.VERSION_NAME`，三者不会再漂。
- 产物：`SimpleChat-1.1.5-release.apk` / `SimpleChat-1.1.5-debug.apk`，
  与 Release 附件同名，发版时不用再手动改名。

## 16.6 遗留

- 弹窗里的「确定 / 取消」仍是上下 14dp，没有并进 `Space.RowPadY`；按钮比列表行更"厚"一点，
  暂按现状保留。
- 真机（尤其 Android 8 / 各厂商 ROM）没有覆盖：通知权限在 13+ 才存在，8.0–12 走默认授予。

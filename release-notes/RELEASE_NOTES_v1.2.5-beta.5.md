# SimpleChat v1.2.5-beta.5

预发布 · Android 构建号 60。可用同签名 APK 覆盖升级，无需卸载旧版。

## Agent Harness 与工具调用

- 重做聊天工具运行时，统一工具注册表、运行时能力状态、工具策略、工具执行器、协议适配器和 Agent Transcript。
- 当前只开放两类聊天工具：联网研究（搜索 / 网页读取）与生图；工具是否调用由模型结合上下文判断，应用负责权限、开关、预算、参数和失败状态校验。
- 搜索开关在 Agent loop 中途变化时会重新读取；关闭后的工具调用会被阻止，不会实际发出网络请求。
- 修复天气等普通问题误调用生图，以及模型依据历史回答错误否认当前工具能力的问题。
- OpenAI Chat Completions、Responses 和 Anthropic 三种协议的工具历史回传分别由适配器处理，为后续 Gemini、Skill、角色卡、世界书和记忆工具预留扩展边界。

## 界面与交互

- 工具调用过程中的过程正文和最终正文增加渐出 / 渐入过渡。
- 回收站顶部由分段开关改为 Material3 Tab；Tab 与标题栏共用设置页背景，浅色、深色和自定义主题下均随页面配色变化。
- 回收站中的清空、彻底删除和垃圾桶图标使用红色危险色；聊天界面的消息删除按钮保持原来的中性色。
- 修复删除中间消息后底部保留旧锚点空间，导致出现大块空白的问题。
- 主题编辑器的高级选项为输入框、输入扩展面板、侧边栏、弹出菜单、回到底部按钮、用户消息气泡和对话大纲提供独立的不透明度开关。

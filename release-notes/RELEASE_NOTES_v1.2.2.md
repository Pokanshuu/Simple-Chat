# SimpleChat v1.2.2

## 新增

- 空输入框按住说话。松手转写并发送，上滑取消并轻震。DeepSeek 官方接入最长 120 秒，其他接入用系统语音识别。
- 等待首个 token 时随机显示加载词。在「设置 → 对话 → 对话行为 → 显示 → 加载词」添加、编辑、删除自定义文案；列表为空时用默认 8 句。「使用主题色」同时作用于加载文案、转圈和省略号。
- 侧边栏置顶分组可折叠展开，标题行高与普通会话一致。
- 横屏（≥ 720dp）下侧边栏与对话并排，侧边栏可折叠。搜索结果留在左侧，选中的对话显示在右侧。
- 支持 OpenAI Responses API。按 API 配置选择协议，读取 `reasoning`、`reasoning_summary_text` 等思考文本。

## 改进

- 长对话压缩后继续发送，以用户消息开头并携带压缩摘要。
- 连续发送保持消息顺序。两条用户消息之间没有有效回复时合并发送。
- 发送失败时显示中文说明和处理建议，并保留请求编号。
- 从模型列表识别上下文、输出上限、深度思考和图片输入能力。已知模型用内置资料，可在「测试连接」、聊天模型菜单或「模型能力」中刷新调整。
- 长草稿的全屏输入改为原地展开。点击展开按钮后输入框向上撑开，收起时缩回，光标和键盘状态不变。按钮浮在文字右上角，半透明圆形。
- 输入框展开时空态提示平滑淡出，收起后按原尺寸恢复。键盘弹出和输入框伸缩与聊天内容逐帧联动。
- 优化长历史滚动和 Markdown 流式渲染。

## 修复

- 修复二次启动时跳过首次引导的问题。只有完成引导后才不再显示。
- 搜索先显示「加载中…」，只有确实无结果时才显示「暂无结果」。
- 折叠的代码块在生成时下方不再留大片空白。生成更多行不会撑大空白。
- 没有思考内容时不再显示空白思考面板。
- 统一思考过程的引导样式。「正在思考」与「已思考」使用相同的圆点、竖线宽度和正文缩进，流式结束切换时不再左右跳动。

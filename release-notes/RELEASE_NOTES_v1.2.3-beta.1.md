# SimpleChat v1.2.3-beta.1

这是 SimpleChat v1.2.3 的首个预发布版本。本次更新替换了同 tag 的构建号 38，修正文案和深色模式显示问题。

## 新增与改进

- 按模型和端点分别处理 DeepSeek Flash、Pro 的工具、标题和思考能力。
- 选择回复文字时，复制结果保留段落间距、列表层级和统一的中点列表符号，并去除 HTML/Markdown 标记。
- 双击对话顶栏可返回顶部。
- 输入框获得焦点时禁用按住说话，并显示“发消息”。
- 缓存命中统计支持 DeepSeek 与 OpenAI 格式的缓存 token 字段。
- 无效 API Key 只显示 Key 错误提示，不再叠加 HTTP 状态或重复的鉴权错误。
- 修复未指定文字颜色的界面文案在深色模式下继承黑色、无法阅读的问题。

## 修复

- 超大请求开始上传后遇到断线时，不再自动重放可能已被服务端处理的请求。
- 网络错误提示区分请求尚未收到响应头，以及服务端已响应但未返回回复的情况。
- 修复部分兼容端点只通过 `prompt_tokens_details.cached_tokens` 返回缓存用量时，命中率显示为 0 的问题。

## 兼容性说明

DeepSeek 的多种兼容端点在模型能力、请求参数和 usage 字段上并不完全一致；“兼容”二字这次确实承担了不少工作。应用按端点分别处理这些差异。

# SimpleChat v1.2.6-beta.3

预发布 · Android 构建号 67 · 2026 年 11 月 25 日

## 主题编辑器

- 底部四个编辑分类（裁切 / 调节 / 文字 / 界面）改为居中排列；内容过长时仍可横向滚动。
- 文字分类的二级分类（文字大小 / 气泡文字 / 回复文字 / 界面文字）同样居中。
- 关闭「自定义颜色」时隐藏当前预览文字色，只保留开关和「使用主题色」；重新开启后恢复颜色选择。

## 字体

- 自定义字体管理弹窗补上圆角，与其它设置弹窗统一。
- 字体选择入口直接弹出字体选择菜单，不再以「系统默认 / 自定义字体」的切换菜单呈现。
- 字体选择行移除行尾单独的加号；点整行即可打开字体列表，菜单内保留「添加字体」「管理字体」。

## 阴影与透明度

- 输入栏、输入面板和所有弹出菜单统一为更浅的 `panel` 投影；抽屉和消息索引使用 `raised`，回到底部按钮使用 `floating`。
- 投影半径随表面面积放大，整体向下偏移，顶边以上不绘制；大面积表面得到更宽、更柔的半影。
- 投影只绘制在元素形状外侧，半透明元素内部不会再透出底下的阴影，并随底色不透明度衰减。
- 输入框描边降到全局 `outline` 的 60%，避免在柔和大投影旁显得生硬。
- 输入栏面板展开改为 300ms 先快后慢缓动；收起不再在最后一帧跳 10dp，展开时的底部投影不再被裁剪。
- 界面底色不透明度默认 100%（实色），透明需要用户主动调低。

## 上下文压缩

- 摘要按当前活跃路径选择：同一会话可保留多份摘要，只使用覆盖最远且最近更新的一份；空摘要按未压缩处理。
- 原地编辑或重试覆盖范围内的消息会删除相关摘要并恢复全量发送；编辑重发 / 重新生成只影响新分支，旧分支摘要保留。
- 恢复已删除消息不会主动让摘要失效；仍在覆盖范围内的消息只存在于本地，不进入请求。
- JSON 备份与 ZIP 归档会带上压缩摘要；恢复后压缩状态保留。边界消息未导出的无效摘要会被丢弃。

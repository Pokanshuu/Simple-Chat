# SimpleChat v1.2.6-beta.3

预发布 · Android 构建号 67 · 2026 年 11 月 25 日

## 主题编辑器

- 底部四个编辑分类（裁切 / 调节 / 文字 / 界面）改为居中排列；内容过长时仍可横向滚动。
- 文字分类的二级分类（文字大小 / 气泡文字 / 回复文字 / 界面文字）同样居中。
- 关闭「自定义颜色」时隐藏当前预览文字色，只保留开关和「使用主题色」；重新开启后恢复颜色选择。

## 字体

- 自定义字体管理弹窗补上圆角，与其它设置弹窗统一。
- 字体选择入口直接弹出字体选择菜单，不再以「系统默认 / 自定义字体」的切换菜单呈现。
- 字体选择菜单新增「添加字体」入口，与右侧加号一样打开本地字体文件选择；「管理字体」保留在菜单底部。

## 阴影与透明度

- 全局阴影统一由 `ShadowTokens` 与 `Modifier.surfaceShadow` 绘制：输入栏、输入面板、菜单、抽屉、回到底部按钮和消息索引共用一套规格。
- 投影只绘制在元素形状外侧，半透明元素内部不会再透出底下的阴影。
- 阴影随底色不透明度衰减：元素越透明，阴影越弱、范围越小；透明度为 0 时不绘制阴影。
- 界面底色不透明度默认 100%（实色），透明需要用户主动调低。

## 验证

- Debug 单测 900 项，888 项通过、12 项跳过、0 项失败。
- `compileDebugKotlin`、`compileDebugAndroidTestKotlin` 构建通过；本次未做设备目视验收。

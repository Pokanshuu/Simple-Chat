# SimpleChat v1.2.6-beta.6

2026 年 11 月 29 日 · Android 预发布 · 构建号 70

> [!WARNING]
> **这是非常早期的预发布测试版，请勿作为日常使用版本。** 它包含尚未经过长期稳定性验证的新功能
> （特别是云同步、可拖拽滚动条与思考展示策略）。安装前请先用「设置 → 数据管理 → 导出所有数据」
> 备份；如果设备上有重要对话，建议在备用设备或测试机上试用。遇到问题请反馈，不要直接覆盖唯一一份数据。

此版本面向测试与反馈：新增收藏夹、分享截图个性化、应用内更新、思考展示策略、时间感知、
可拖拽滚动条与消息胶囊，并首次提供云同步（WebDAV）的账号与同步入口。同时修复了大量
版本比较、导出落盘、收藏数据安全与分享可读性问题。

## 亮点

- **收藏夹。** 在消息操作栏或长按菜单收藏，支持多个收藏夹、备注、搜索与按会话 / 按收藏夹分组；删除会话不会删掉收藏的正文与图片，JSON 与 ZIP 备份都包含收藏。
- **分享截图个性化。** 导出的截图可以跟随当前主题、字体、字号与壁纸，并带品牌行；壁纸保护层保证正文可读。
- **应用内更新。** 「关于」页可直接检查 GitHub Releases、查看更新说明、下载并校验 sha256，然后交给系统安装器。
- **思考展示策略。** 设置 → 对话行为里可以选择生成中与生成结束后如何展示思考内容，支持流式中「展开全部」。
- **时间感知。** 模型现在知道当前日期、星期、时刻、时区与"距上一条消息多久"，回答"今天几号"更可靠。
- **可拖拽滚动条。** 快速滚动时滚动条变粗可拖，拖动时会显示目标消息的首行预览。
- **云同步（测试）。** 设置 → 数据管理 → 云同步可填写 WebDAV 网盘，手动同步会话；冲突会保留副本，不会覆盖本机内容。

## 改进与修复

- 预发布版本号参与比较：beta 用户在同号正式版发布后也能收到更新提示，"beta.10 > beta.9" 这类比较也正确。
- 修复导出到部分系统文件管理器后留下 0 字节文件的问题（写入后回读校验、必要时改用原生文件描述符重写）；导入报告与更新包换名失败时回退复制，兼容鸿蒙 / 卓易通等容器环境。
- 收藏数据安全：「删除所有历史对话」按设计清空收藏；彻底删除消息不再误删收藏图片；批量加夹不再丢归属；搜索结果会刷新，切换筛选/分组会清空多选。
- 收藏视觉与栅格：收藏与收藏夹改为星标图标，搜索框重做以对齐页面网格；移除空状态里的说明性文字。
- 分享可读性：壁纸保护层下限浅色 0.55 / 深色 0.65；关闭 Simple Cat 图标后导出图不再带猫标。
- 抽屉关闭后不再漏出左侧投影；主题编辑器字体选择行铺满宽度。

## 已知问题

- 云同步是本期最早的功能，仅提供**手动同步**：没有后台自动同步，也不同步收藏夹、设置、壁纸与字体；「删除云端数据」尚未提供。首次使用前请务必让两台设备分别备份一次。
- 云同步目前只同步**活动会话**；回收站里的会话不参与同步。冲突处理会把远端内容另存为本地副本，极端情况下可能产生多条副本会话。
- 思考内容的"生成中全部展开"没有高度上限，超长思考依赖分段渲染；低端设备在极长思考时仍可能出现掉帧。
- 收藏跳转到"原会话在回收站 / 原消息已删除"的分支处理、带图片收藏在备份中的内存表现仍是后续工作。
- 应用内更新只能在正式版发布后检测到更新；预发布之间不会互相提示。

## 安装与升级

- 签名 APK 支持 Android 8.0 及以上版本；可直接覆盖安装同一签名的旧版本。
- 覆盖安装不会删除本地数据，但**强烈建议先导出备份**，尤其是准备试用云同步时。

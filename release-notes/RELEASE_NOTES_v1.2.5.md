# SimpleChat 1.2.5

**发布渠道：预发布｜Android 构建号：56｜发布日期：2026-11-23**

本说明汇总自 1.2.4 以来的用户可见变更。使用同签名 APK 可覆盖升级，无需卸载旧版。建议升级前导出一份 SimpleChat 原生备份。

## 新增功能

| 功能 | 说明 |
| --- | --- |
| 主题与壁纸 | 在「设置 → 外观 → 自定义主题与壁纸」预览示例对话，裁切、翻转或调整壁纸。也可在对话设置中为当前聊天单独设置壁纸，移除后恢复全局壁纸。 |
| 悬浮界面 | 分别调整底色不透明度、亚克力强度和主题色浓度，并按控件选择是否应用亚克力或主题色。默认卡点为 85% 和 25%，升级不会自动启用亚克力。 |
| 自定义字体与图标 | 分别为界面、本人消息和模型回复设置字体。「主题」中的图标风格菜单可切换经典图标和 Simple Cat，并提示重新打开应用。Simple Cat 风格包含猫咪加载动画。 |
| 第三方声音 | 在「设置 → API → 独立工具 API」配置 DashScope 或 OpenAI 兼容语音。配置完成后可在「朗读」试听、选择音色并用于聊天朗读。支持千问预设、补齐内置音色和填写自定义音色 ID。 |
| DeepSeek 分享导入 | 从「设置 → 备份 → 导入备份」粘贴公开分享链接，预览并导入当前对话路径、思考过程、搜索和网页阅读记录及引用。大型分享使用临时文件及流式写库，下载上限 1 GB。 |
| 会话回收站 | 已删除的会话可恢复或彻底删除，超过 15 天自动清理。 |

## 改进与修复

- **搜索和网页读取**：独立搜索工具可结合近期对话规划查询、补查和读取原文；部分读取失败时保留已取得的信息。修正不同协议下的工具路由与联网能力判断。搜索、文件和声音 API 关闭后隐藏各自的配置项。
- **生图和改图**：仅收到实际图片才显示成功；明确的生图请求未调用工具时可选「直接生成」。改图优先使用本轮图片，也可使用当前分支近期生成的图片；缺少参考图时会提示补图。修正思考、生成状态、图片与正文的显示顺序。
- **长对话**：压缩上下文时跳过不可读附件，保留 1.2.4 的记忆内存保护。修复部分对话滑动时的闪退，以及应用主题色后长按录音提前结束的问题。
- **显示与交互**：聊天和设置在宽屏居中限宽，壁纸编辑工具移到预览右侧。切换裁切页保留已保存构图；壁纸平滑淡入；正文和思考文字的渐变不再遮住壁纸。流式正文按帧间隔平滑跟底；来源胶囊逐渐展开，减少换行和新来源出现时的跳动。修复侧栏边线、底部露字、菜单阴影裁切和夜间悬浮控件底色；来源胶囊仅跟随底色不透明度。
- **亚克力**：收窄壁纸模糊调节范围，仍支持 0%。Android 12 及以上的实时亚克力不再因省电模式关闭。声音快捷操作无内容可补时自动隐藏。
- **朗读**：停止时取消正在进行的合成或下载，并清理临时音频。修复部分音色试听重复请求和错误提示残留。
- **消息删除**：删除当前版本或所有版本时均保留后续对话分支。新增独立的“多选并删除”入口；多选删除会移除所选问答中各消息的所有版本，其他消息与下游分支会接回保留。删除前二次确认。

## 已知限制

- DeepSeek 分享快照不含其他分支和附件原件。DeepSeek v3 ZIP 是兼容交换格式，不保留全部 SimpleChat 专有字段；要无损往返，请使用 SimpleChat 原生 ZIP。
- 第三方语音暂不支持从服务端刷新音色列表。自定义或克隆音色需先在服务商处开通。第三方功能的实际可用性取决于所配置的服务。
- Android 12 以下的悬浮控件不支持实时背景模糊，仍可调节混色和底色不透明度。

# SimpleChat v1.2.3

v1.2.3 改进了长对话切换 DeepSeek 端点时的兼容性，新增跨对话记忆、摘录分享、用量统计和诊断入口。本文列出从 v1.2.2 升级后的变化。

## 新增功能

### 跨对话记忆

- 在「设置 > 记忆」开启跨对话记忆，可调整参考会话数。应用在后台从其他会话的当前分支检索相关片段，并随本轮问题发送给当前端点。停止生成时会取消正在进行的检索。
- 设置首页显示记忆状态。记忆页面提供增强记忆的说明，包括本地模型、索引及资源占用。增强记忆尚未开放。

### 分享、语音和用量

- 选中回复中的文字后，选择「分享摘录」可将片段导出为图片。摘录沿用现有图片分享样式，包含日期和 AI 生成提示。
- 在「设置 > 对话行为」可关闭长按输入框说话。输入框聚焦时停用长按说话，便于编辑文字。
- 查看当前会话与全部会话的请求次数、输入和输出 Token、缓存命中，以及近 30 天每日 Token 图表。用量以服务端上报的数据为准。
- DeepSeek 官方端点显示余额和预估费用，可刷新余额或打开充值页面。第三方端点显示「用量统计」，省略余额入口和 DeepSeek 费率说明。

### 设置和诊断

- 将外观、语言、预设、记忆、对话行为和朗读音色放入「个性化」，统一设置首页和子页的间距。API 入口显示当前配置名称，记忆位于预设下方。
- 在「关于 > 诊断」统一查看运行日志和崩溃记录，支持复制、保存为文本和分享。最近一次导入报告在「备份诊断」中单独提供。
- 数据管理中的「导入备份」有独立入口，支持 SimpleChat、Chatbox 和 DeepSeek v3 备份。
- 关于页合并版本与更新入口，并将项目地址和开源许可归入「项目」。点击 MIT 可查看许可证全文。页面底部增加合法使用提示。

## 改进和修复

### DeepSeek 模型和接口

- 在同一会话切换 Flash、Pro、OpenAI 兼容端和 Anthropic 兼容端时，按当前路由重新组装请求。保留原有文字历史和本地记录，按目标模型能力跳过旧工具块、图片和文件引用。
- 按模型和协议发送搜索、读链接、服务端标题、思考和采样参数。官方 Flash 支持内置工具，Pro 可通过独立搜索 API 获取资料。网关保留自己的模型名称和 URL 前缀。官方配置中的旧 Flash 别名会映射到 `deepseek-flash`。
- 根据配置识别 Chat Completions、Responses 和 Anthropic Messages。切换协议时规范化已填写的 DeepSeek 官方路径，避免重复拼接。模型列表刷新失败时会结束加载。
- 统一解析 DeepSeek 和 OpenAI 兼容格式的缓存命中字段。每轮单独记录服务端用量，修复沿用上一轮缓存数字的问题。升级时保留旧消息，缺失的缓存统计按未知处理。

### 长对话和请求恢复

- 优先发送完整历史。端点明确报告输入超限时，自动压缩较早的消息，并用原模型和原问题继续。编辑压缩范围内的原消息后，旧摘要会失效。
- 遇到 `Content Exists Risk` 时，可选择「跳过附件和工具重试」。文字重试保留当前模型、历史正文和有效摘要，跳过附件、搜索与读链接。本地聊天和附件仍可查看。
- 服务端明确拒绝可选附件或工具时，可自动降级一次并继续文字回复。独立搜索或抓取失败时，跳过该工具继续主回答。可关闭或静音附件与工具跳过提示。
- 快速重复触发「继续生成」或「重新生成」时，只启动一次请求，避免产生重复回复分支。
- 请求开始上传后遇到断线时停止自动重放。网络提示区分未收到响应头和收到响应后尚无回复两种情况。收到 SSE 错误事件后立即结束读取。
- 无效 API Key 显示单一鉴权提示。编辑已有消息时保留草稿。

### 阅读、选择和 Markdown

- 双击对话标题可直接回到顶部。回顶时暂停自动跟底，避免滚动途中闪回底部。
- 等待正文期间持续显示加载词。正文开始显示后，加载词渐隐。「正在思考」和「已思考」使用 ✨ 图标。
- 选字前后保持 Markdown 布局一致。复制结果去除格式标记，保留段落空行和嵌套列表缩进，并统一无序列表符号。
- 修复流式输出中的 Markdown 链接边界，避免未收完整的链接干扰已显示的正文。
- 改进聊天和分享图片中 LaTeX 的行内对齐、自然换行、窄屏显示及复杂边框命令的兼容性。公式也可在列表、引用和表格中渲染。遇到无法渲染的语法时保留原始公式。
- 修复深色模式下部分未指定颜色的文字不可读的问题。

### DeepSeek v3 备份

- 改进 DeepSeek v3 ZIP 的导入和导出，按官方结构写出会话和分支，保留正文、思考、引用，以及可识别的搜索、读链接、打开网页和页内查找结果。
- 改进图片附件原件与元数据的匹配。DeepSeek v3 归档可恢复图片原件，非图片附件不在该格式的原件恢复范围内。

## 已知问题

- 有存档导入后切换 Pro 仍触发 `Content Exists Risk` 的反馈。使用合成历史的长对话验收未复现该问题，实际触发条件仍待定位。

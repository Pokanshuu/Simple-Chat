# SimpleChat v1.2.5-beta.2

预发布 · Android 构建号 51。使用相同签名的安装包可覆盖升级，保留聊天和设置。

## DeepSeek 分享导入

- 在「设置 → 备份 → 导入备份」中粘贴 DeepSeek 公开分享链接，预览后导入本地会话。
- 导入分享快照提供的当前对话路径、思考过程、搜索记录、网页阅读记录和引用。
- 分享快照不包含其他对话分支；图片或文件只有元数据，没有原件，无法恢复。
- 长对话使用临时文件与流式写库，下载上限为 1 GB，导入期间显示进度。

## 外观、语音与回收站

- 新增自定义字体，可分别设置界面、本人消息和模型回复字体。
- 新增聊天壁纸、裁剪和调整选项，以及可调透明玻璃界面。
- 新增第三方语音 API 配置入口；本版仅包含配置，不包含语音合成通道。
- 删除的会话移至回收站，可恢复或彻底删除；回收站内容 15 天后自动清理。

## 修复与验证

- 修复 DeepSeek 分享对话预览的格式化崩溃。
- 来源：PR #9 与 DeepSeek 分享链接导入。
- 单元测试：844 项通过、0 失败、10 项按条件跳过。
- Release APK 构建成功；包版本 `1.2.5-beta.2`、构建号 51，APK v2 签名验证通过。

# SimpleChat v1.2.5-beta.3

预发布 · Android 构建号 52。使用相同签名的 APK 可覆盖升级，无需卸载旧版。

## 主题与壁纸

- 「设置 → 外观 → 自定义主题与壁纸」集中提供裁切、画面调节和界面效果，可以用示例对话预览。
- 底色不透明度、亚克力强度和主题色浓度互相独立；可以按控件选择是否应用亚克力和主题色。已有壁纸不会因此自动开启亚克力。
- 对话设置支持当前聊天的专属壁纸，移除后恢复使用全局壁纸。
- 横屏和平板上的聊天、设置居中限宽，壁纸编辑工具在宽屏放到预览右侧。

## 修复

- 修复开启界面主题色后，长按录音可能立刻结束的问题。
- 修复部分对话滑动时的闪退；恢复「回到底部」按钮。
- 流式正文和深度思考渐变不再给壁纸盖上底色；壁纸加载后平滑淡入。
- 恢复夜间模式的深灰控件层次，加深悬浮控件投影，并修复侧栏分隔线和底部的异常显示。

## 验收与校验

- 单元测试：842 项通过、0 项失败、10 项跳过。
- Android 14 模拟器：主题色开启后的长按语音、横屏侧栏透明和不透明状态均通过回归；使用公开签名版 beta.2 覆盖升级到 beta.3 后启动正常。

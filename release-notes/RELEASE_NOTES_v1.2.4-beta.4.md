## SimpleChat 1.2.4 Beta 4

- GPT 支持关闭思考时会显式发送关闭参数。必须思考的 GPT 模型从最低支持档位起步。
- 官方 OpenAI Responses 支持通过星星菜单切换联网搜索。专用搜索模型显示为开启并锁定。
- 星星菜单增加「配置 API」入口。新建 API 配置按钮增加加号图标。
- 生图 API 和聊天模型原生生图改为互斥，独立生图设置使用「默认图片模型」。
- 生图输入框支持按住说话。附件菜单入口改为一行排列。
- 当前对话记忆设置分为灰色小标题、「记忆对话」开关和说明。导出入口改为「导出全部对话（SimpleChat 备份）」。
- 外观设置新增「图标」，默认使用 Simple Cat，可切回经典图标。切换会同步更新应用内的对话气泡和桌面图标。

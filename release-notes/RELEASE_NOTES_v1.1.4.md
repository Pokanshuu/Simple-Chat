# SimpleChat v1.1.4

本次更新新增自动朗读和 API 配置管理，并改进大规模对话迁移、消息发送与长文本显示的可靠性。

## v1.1.4 修订版（构建 20）

- **搜索后回到底部。** 修复搜索定位预留空间残留，导致点击“回到底部”后出现大段空白的问题。回到底部、发送、重试或继续生成时恢复正常布局。
- **可横向滚动的表格。** 列宽按内容保留可读空间，宽表格可左右滑动，不再强行压进屏幕导致竖排或裁切；表头与正文统一滚动，内容完整显示。
- **表格手势。** 从表格内开始的横滑优先交给表格，滑到边界继续拖动也不打开会话抽屉或消息索引；纵向拖动仍可滚动消息。

## 构建 19 修复

- **首次搜索跳转。** 改进首次加载会话、键盘收起与搜索定位的协调，搜索期间暂停自动跟底，避免定位后被拉到回复末尾。
- **返回搜索。** 从结果进入对话后，支持侧滑或系统返回回到刚才的搜索页，保留关键词、结果与滚动位置。
- **搜索外观。** 修复搜索当前会话时，其全部命中结果被误显示为灰色选中卡片的问题。底色只标记上次点击的单条消息，返回搜索时保留，点击其他结果时转移，修改关键词时清除。
- **历史图片发送。** 图片经实际解码后转换为标准 JPEG 再发送，避免仅凭文件头和尺寸放行异常图片。损坏或设备无法解码的图片只在本轮请求中跳过，本地原件保留；同时修复仅含落盘图片的历史消息被错误忽略的问题。
- **图片跳过提醒。** 横幅的关闭按钮左侧新增“不再提醒”，选择后持久生效。可在设置中的“图片跳过提醒”重新开启。
- **全局搜索。** 同一会话的多条命中分别列出，显示用户消息／AI 回复、消息日期与多版本标记；每条结果可独立跳转，未激活分支也可找到。结果较多时可继续加载。
- **搜索定位。** 关键词位于输入栏上方可阅读区域的中间偏上，按输入区实际高度避让。首条短消息、末尾消息与长消息分页均保留定位空间，高亮渐隐后位置不变。
- **表格高亮。** 修复表格命中未真正绘制高亮的问题，继续保留正常 Markdown 排版。

本次修订保留版本名 1.1.4，versionCode 递增至 20，以便覆盖安装；Release 附件和校验值已同步更新。

## 新增功能

- **自动朗读。** 可通过对话页右上角、新建对话左侧的喇叭按钮启用。新回复生成完成后自动朗读；关闭时停止当前播放。使用设置中已选择的朗读音色。
- **API 配置管理。** 可保存多组服务商、地址、模型、协议和 API Key，支持新建、复制、重命名、删除及一键切换。修改自动保存，原有配置在升级后保留，Key 继续加密存储。

## 改进

- 改进 DeepSeek 官方记录和 SimpleChat JSON/ZIP 备份的读取方式，降低大文件、长会话及图片导入导出的内存占用。
- 导入结果提供会话数量核对、消息写入数量与失败原因。空间不足、内存不足和归档缺失条目可明确区分，并支持导出详细对账文件。
- JSON 和 ZIP 导出增加生成、保存进度，保存成功后才显示完成；失败时清理临时文件。
- 超长消息采用分页显示，降低页面布局开销。搜索结果可定位到对应消息、分支与关键词所在页面。
- 为 `\scalebox`、`\resizebox` 等特殊 LaTeX 排版提供兼容显示；无法解析时展示完整原文，并保留查看源码的入口。
- 系统朗读支持长文分段，改善播放完成状态和停止响应。

## 修复

- 修复搜索跳转后正文渲染及深色主题文字颜色异常。跳转后保留正常排版，关键词短暂高亮后渐隐。
- 修复部分设备在发送大段文本、编辑消息或快速切换会话时，可能出现的崩溃与状态错乱。
- 修复消息尚未保存就清空输入的问题。保存失败时保留输入；回复无法保存时提供明确提示。
- 修复上下文压缩后发送可能生成空请求的问题。
- 修复部分备份导出为 0 字节、超大消息导出失败，以及空字段读取异常。
- 修复部分导入路径中空会话、断链消息及同名会话处理不一致的问题。
- 修复导入消息 ID 冲突可能影响已有会话的问题，冲突会话现在会回滚并报告失败。
- 修复分叉会话共用图片时，删除原会话可能使副本丢图的问题。
- 修复导入失败后附件清理范围不正确，以及单会话备份缺少关联预设的问题。
- 修复停止生成时网络连接可能仍在等待的问题。

## 使用说明

- 自动朗读默认关闭。打开历史记录不会自动重读；系统朗读需要设备具备可用的 TTS 引擎。
- API 配置和密钥仅保存在本机，不包含在对话备份中。换机时需要重新配置 API Key。
- 增量导入按会话 ID 跳过已存在的会话，适合补入此前未成功导入的会话。
- 特殊 LaTeX 兼容显示优先保留内容，缩放、旋转和定宽效果可能与完整 LaTeX 排版不同。
- DeepSeek 官方记录中的搜索/读链过程及部分非图片附件仍有导入限制；导入时会显示相关说明。

## 验证说明

- 构建 18 补充验证：实际 Android 解码损坏 PNG、透明 PNG、CMYK JPEG、WebP 与超尺寸图片；双协议历史图片请求、提醒持久化、109 条搜索结果的分页与角色/日期/分支跳转。深浅主题共 12 个截图场景验证关键词位于可阅读区域中间偏上，高亮渐隐后位置稳定。构建 19 补充完整页面流程：首次从搜索页点击长回复、重复跳转、系统返回及右滑返回，保留搜索词和列表位置；验证同一会话仅一条消息带选中底色，修改关键词后清除。

- 在 Java 堆上限为 192 MB 的 Android 34 模拟器上验证了大文件迁移闭环：2768 个会话、71472 条消息完成导入、导出和恢复，正文、思考与图片哈希一致。
- 完成了连续发送/停止、快速切换、压缩后发送、写库失败保留输入，以及 2100 万字符输入的发送与页面显示测试。
- 新增功能通过单元测试及模拟器回归。实际朗读效果取决于设备 TTS 引擎或所选官方语音服务。

支持 Android 8.0 及以上版本。

# SimpleChat v1.2.4 发布说明

2026 年 11 月 21 日 · 正式版 · 构建号 49（覆盖更新）

与 v1.2.3 相比，此版本新增会话内生图、单独管理每个对话的记忆，以及更精细的搜索和朗读控制。此说明汇总了四个 Beta 版本和正式版的改动。

## 安装和升级

下载 `SimpleChat-1.2.4-release.apk`。支持 Android 8.0 及以上版本，使用相同签名的 v1.2.3、v1.2.4 Beta 和 v1.2.4 构建号 48 均可直接覆盖安装。首次从旧数据库版本启动时，应用将本地数据库升级至架构版本 13。

## 在对话中生成图片

- 您可以在对话中直接要求模型调用生图能力，也可以在输入框旁选择「＋ → 生成图片」。输入画面描述，也可以按住说话。支持的模型可以使用参考图，并按模型提供可用的宽高比和尺寸。等待时可以停止生成，失败后可以重试，也可以使用同一段描述生成另一个版本。
- 在「设置 → API 配置 → 独立工具 API → 生图 API」连接 OpenAI Images、Gemini 或 Qwen/DashScope。可以测试连接、从当前端点获取模型列表，或手动输入模型 ID。可以设置默认模型和尺寸，返回时自动保存配置。Gemini 支持 `generateContent` 和 Interactions，应用会按模型选择路径。
- 聊天模型可以通过 OpenAI 或 Anthropic 兼容工具调用使用独立生图服务。「生成一个穿着 24 号球衣的运动员」等描述不必包含“图片”二字。单问「你可以生成图片吗？」、讨论图片或索要提示词不会触发生图。支持生图的 Gemini 模型和 Responses 端点也按当前消息判断是否生成。独立服务与聊天模型原生生图互斥。
- 出图后可以接着说「把它改成印象派风格」。改图使用当前上传的参考图，或当前分支紧邻的上一张生成图；重试沿用同一张参考图。支持图片输入的聊天模型可以在相关追问中看到原图；纯文本模型可以调用生图 API 改图，但不能直接看图。
- DeepSeek 官方 Chat Completions 在关闭思考且收到明确的生图请求时会要求调用生图工具；思考模式和兼容网关仍由模型自动选择。
- 生成的图片随回复保存在会话中。打开图片后，可以浏览当前会话中的图片、双指捏合缩放并拖动查看细节，也可以保存原图。重试会复用已保存的参数，生图连接中途断开时会自动重试一次。备份保留生图消息标记和已保存的请求参数。

## 管理记忆、搜索和朗读

- 在当前对话的设置中关闭「记忆对话」。关闭后，该对话既不会读取其他对话的记忆，也不会为其他对话提供记忆。可以在发送首条消息前关闭。
- 搜索默认只检查当前分支。可在「设置 → 对话行为 → 搜索」中启用非活动分支或深度思考搜索。命中思考内容时，应用会展开并高亮对应文字。
- 「设置」中的朗读总开关可以关闭朗读功能，并隐藏音色和对话中的朗读入口。
- 更新了全新应用图标 Simple Cat，可在「设置 → 外观 → 图标」切换 Simple Cat 和经典图标。默认使用 Simple Cat，同时应用于桌面启动图标和界面中的对话气泡。您可以随时切换回旧版图标。

## 配置模型和工具

- 适配了 Gemini、GPT 和 Claude 的上下文窗口、输出上限、识图和思考档位。应用优先使用服务返回的能力和手动设置。
- Claude 原生协议支持自适应思考和强度。GPT 在 Chat Completions 和 Responses 中按模型发送思考强度和输出上限。支持关闭思考的模型会收到明确的关闭参数，必须使用思考的模型从最低支持档位起步。
- OpenAI 官方 Responses 可从星星菜单切换联网搜索。专用搜索模型始终启用该选项。也可以从这个菜单快速打开「配置 API」。
- 独立搜索、文件和生图 API 设置在聊天配置之间共享。切换聊天配置后可以继续使用这些工具。

## 修复和界面改进

- 限制跨对话记忆检索扫描的会话数、分支深度、消息数和单条文本长度，降低大量或超长历史触发内存溢出和闪退的风险。本地完整消息会保留。
- 调整附件菜单布局，统一模型选择入口，并将备份入口命名为「导出全部对话（SimpleChat 备份）」。

## 验收结果

- 单元测试通过 823 项，跳过 10 项。
- 模拟器验证了覆盖安装和启动、双指放大和缩回、原图保存、生图参数恢复、工具 API 设置、朗读开关和跨对话记忆。
- 回归测试覆盖自然语言生图、结合上图的改图指令、能力询问、视觉附件与 DeepSeek 工具请求。第三方生图端点未逐一使用真实凭证验证。

## 已知问题

DeepSeek 兼容 ZIP 导出后重新导入时，部分 SimpleChat 专用字段无法原样恢复，包括原始 ID、会话和消息的模型字段、系统提示词、会话预设关联及部分附件和回复过程元数据。需要在 SimpleChat 中完整恢复时，请选择「导出全部对话（SimpleChat 备份）」。

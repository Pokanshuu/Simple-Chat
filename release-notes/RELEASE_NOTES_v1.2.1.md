# SimpleChat v1.2.1

1. 修复删除首条或中间分支后无法切换的问题，剩余分支可正常来回切换。
2. 优化分支删除性能，减少含大量历史的会话中的数据库读取。
3. 优化长对话用量统计，复用未修改消息的 token 估算结果。
4. 复制回复或代码后，按钮会短暂变成对勾，提示复制完成。

5. 优化聊天滚动条，滑过长消息时滑块连续移动，连续滑动时保持可见。

Android 构建号为 34。已安装 v1.2.1 构建号 33 的用户可从本页下载 APK 覆盖安装。同版本名不会触发应用内更新提示。

构建号 34 的源码见 [提交 2484bf8](https://github.com/Pokanshuu/Simple-Chat/commit/2484bf89d5254827065a72228d5fd8ae1441fea7)。

# SimpleChat v1.2.5-beta.4

预发布 · Android 构建号 54。可用同签名 APK 覆盖升级，无需卸载旧版。

## 第三方声音

- 「设置 → API → 独立工具 API → 第三方声音 API」支持 DashScope 与 OpenAI 兼容服务，已接通音色试听和聊天朗读。
- 可以按协议填入内置音色，也可以手动添加音色 ID 和显示名称；暂不支持从服务端刷新音色列表。
- 停止试听或朗读时会取消正在进行的合成或下载，并清理临时音频。

## 设置交互

- 第三方声音、搜索和文件 API 的总开关放在页首，关闭时隐藏下方配置。配置齐备并添加音色后，朗读页才显示第三方音色。
- 「外观 → 主题」新增图标风格菜单，可直接切换经典图标和 Simple Cat。

## 修复

- 修正联网搜索工具路由与回答能力判断。
- 从「调节」切到「裁切」时保留壁纸当前构图。
- 底色不透明度 85%、亚克力强度 25% 各有独立的默认吸附点。
- 正文下方「N 个来源」胶囊只跟随底色不透明度，不应用主题色或亚克力。
